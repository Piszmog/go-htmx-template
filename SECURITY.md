# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately through GitHub's
[security advisories](https://github.com/Piszmog/go-htmx-template/security/advisories/new)
instead of opening a public issue.

You can expect an initial response within a few days. Once a fix is available it
ships as a patch release, and the advisory is published with credit unless you
prefer to remain anonymous.

## Supported Versions

Only the latest release receives security fixes.
